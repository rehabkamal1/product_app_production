## ✨ مميزات المشروع

### 🎯 المميزات الأساسية

- ✅ **عرض المنتجات**: عرض قائمة شاملة بجميع المنتجات مع الصور والأسعار والتقييمات
- 🛒 **سلة التسوق**: إضافة المنتجات إلى السلة وإدارة الكميات
- 📱 **واجهة متجاوبة**: تصميم متجاوب يعمل على جميع الأجهزة (الهاتف والتابلت والحاسوب)
- 🔐 **نظام المستخدمين**: تسجيل دخول وتسجيل حسابات جديدة
- 🔍 **تفاصيل المنتج**: عرض معلومات مفصلة عن المنتج مع صور متعددة
- ⭐ **نظام التقييم**: عرض تقييمات المنتجات
- 📊 **إدارة السلة**: عرض، تعديل، وحذف المنتجات من السلة

### 🎨 المميزات التصميمية

- 🌈 **تصميم عصري وجذاب**: واجهة مستخدم حديثة وسهلة الاستخدام
- 🎭 **تأثيرات بصرية**: animations وtransitions سلسة وجميلة
- 🎯 **تجربة مستخدم محسّنة**: تفاعل سريع وسلس مع التطبيق
- 📐 **نمط تصميم Bootstrap**: استخدام Bootstrap 5.3.3 للتصميم المتقدم
- 🌙 **ألوان احترافية**: نظام ألوان متناسق وجمالي

### ⚡ المميزات التقنية

- 📡 **بناء قائم على الكومبونينت**: معمارية نظيفة وسهلة الصيانة
- 🔄 **Routing متقدم**: نظام توجيه فعال بين الصفحات
- 🎯 **State Management**: إدارة حالة التطبيق بكفاءة
- 📦 **Lazy Loading**: تحميل الكومبونينت عند الحاجة
- ⚙️ **Services قوية**: خدمات منفصلة لإدارة البيانات والمنطق

## 🚀 تشغيل المشروع

### تشغيل خادم التطوير

```bash
npm start
```

أو بشكل مباشر:

```bash
ng serve
```

### الوصول إلى التطبيق

بعد تشغيل الأمر، افتح متصفح الويب وانتقل إلى:

```

```

### الميزات أثناء التطوير

- **Hot Module Replacement (HMR)**: إعادة تحميل تلقائي عند تعديل الملفات
- **Live Reload**: تحديث فوري للصفحة عند الحفظ
- **Debugging**: إمكانية استخدام أدوات المتصفح للفحص والتصحيح

## 🏗️ البناء والإنتاج

- Netlify
- GitHub Pages
- أي خادم ويب تقليدي

## 🧩 الوحدات والمكونات

### 1. **Product Card Component** 📦
يعرض بطاقة فردية للمنتج مع:
- صورة المنتج
- اسم وسعر المنتج
- التقييم والحالة (متوفر/غير متوفر)
- زر إضافة للسلة

### 2. **Product List Component** 📋
يعرض قائمة بجميع المنتجات:
- شبكة منتجات متجاوبة
- تحديث ديناميكي
- معالجة الأحداث من الكومبونينت الفرعي

### 3. **Product Details Component** 🔍
يعرض معلومات كاملة عن المنتج:
- معرض صور متعدد
- معلومات شاملة (الماركة، والفئة)
- زر الشراء والعودة

### 4. **Header Component** 🎯
شريط التنقل العلوي:
- روابط التنقل
- عرض عدد المنتجات في السلة
- أيقونة السلة

### 5. **Cart Component** 🛒
صفحة سلة التسوق:
- عرض المنتجات المضافة
- تعديل الكميات
- حساب المجموع
- إزالة المنتجات

### 6. **Login Component** 🔐
صفحة تسجيل الدخول:
- إدخال البريد الإلكتروني وكلمة المرور
- التحقق من البيانات
- رسائل الخطأ

### 7. **Register Component** ✍️
صفحة التسجيل:
- استمارة تسجيل شاملة
- التحقق من الصحة
- إنشاء حساب جديد

## 🏛️ المعمارية والبناء

### معمارية الطبقات

```
┌─────────────────────────────────┐
│     UI Components Layer         │
│  (Product Card, List, etc.)     │
└────────────────┬────────────────┘
                 ↓
┌─────────────────────────────────┐
│     Services Layer              │
│ (Data & Business Logic)         │
└────────────────┬────────────────┘
                 ↓
┌─────────────────────────────────┐
│   Routing & Navigation          │
│       (App Routes)              │
└─────────────────────────────────┘
```

### تدفق البيانات

1. **الكومبونينت** يطلب البيانات من **Service**
2. **Service** تعيد البيانات من API أو التخزين المحلي
3. **الكومبونينت** يحدّث العرض بالبيانات الجديدة
4. **المستخدم** يتفاعل مع الواجهة (الضغط على زر، إلخ)
5. **الكومبونينت** يرسل الأمر للـ **Service** لتحديث البيانات
